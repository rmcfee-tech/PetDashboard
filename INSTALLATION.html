Overview

Pet Dashboard is a free, offline-first web app for tracking your pet's health, training, grooming, expenses, journal entries, photos, and daily life. It works on any modern browser — no account, no server, no cloud required.

Privacy Your data lives in a single JSON file on your device. It never leaves your computer unless you export it.

Windows Installation

Quick Start (Recommended)

  1. Download or extract the Pet Dashboard folder to a convenient location (e.g., C:\Users\YourName\Documents\PetDashboard).
  2. Double-click start-server.bat.
  3. A black console window will open and your default browser will launch automatically to http://localhost:8934/index.html.
  4. Leave the console window open while using the app. Closing it stops the server.
Requires Python or Node.js The launcher script uses Python's built-in HTTP server (comes pre-installed on most Windows machines) or Node.js. If neither is found, install Python from python.org (check "Add to PATH").

Installing as a PWA (Installed App)

Once the server is running, you can install Pet Dashboard as a standalone app:

  1. Make sure the server is running (the console window is open).
  2. In your browser's address bar, look for the "Install" icon (usually a monitor with a downward arrow, or three dots → "Install Pet Dashboard").
  3. Click it and follow the prompts.
  4. Pet Dashboard will now open in its own window — separate from your browser, with its own desktop icon.
Offline Support Once installed, the app caches itself and works fully offline. You don't need the server running for the installed app.

macOS / Linux Installation

Quick Start

  1. Open Terminal and navigate to the Pet Dashboard folder: 
    cd ~/Documents/PetDashboard
  2. Make the launcher executable (first time only): 
    chmod +x start-server.sh
  3. Run the launcher: 
    ./start-server.sh
  4. Your browser will open automatically. Leave the Terminal window open.

Alternative: Use Python Directly

If you prefer not to use the launcher script:

cd ~/Documents/PetDashboard
python3 -m http.server 8934

Then open http://localhost:8934/index.html in your browser.

Installing as a PWA

Same as Windows — look for the install icon in your browser's address bar when the server is running.

Android Installation

Option A — Same Wi-Fi, Quick & Temporary

  1. Run start-server.bat on your Windows/Mac computer.
  2. Find your computer's local IP address:
    • Windows: Open Command Prompt, run ipconfig, look for "IPv4 Address" (e.g., 192.168.1.42).
    • macOS/Linux: Run ifconfig or ip a.
  3. On your Android phone (same Wi-Fi), open Chrome and go to: 
    http://192.168.1.42:8934/index.html
    (Replace 192.168.1.42 with your actual IP.)
  4. Chrome will show an "Install app" prompt, or open the ⋮ menu → "Add to Home screen".
Temporary This only works while your computer's server is running. For permanent access, use Option B.

Option B — Free Static Hosting (Recommended)

Since Pet Dashboard has no backend, any free static hosting works:

  1. Upload all Pet Dashboard files to GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
  2. Get your URL (e.g., https://yourname.github.io/pet-dashboard/).
  3. Open that URL on your phone's Chrome.
  4. Tap ⋮ → "Install app" or "Add to Home screen".
Permanent Offline Support Once installed from a hosted URL, the app works fully offline on your phone — no computer needed.

iOS (iPhone / iPad) Installation

  1. Run the server on your computer (see Windows or macOS instructions above).
  2. Find your computer's local IP address (see Android section).
  3. On your iPhone/iPad (same Wi-Fi), open Safari and go to: 
    http://192.168.1.42:8934/index.html
  4. Tap the Share button (square with upward arrow).
  5. Scroll down and tap "Add to Home Screen".
  6. Tap "Add" in the top-right corner.
Safari Limitation iOS Safari doesn't support the File System Access API, so your data will be saved as downloadable JSON files. You'll use "Open" in Settings to re-open the last file. This works perfectly — you just save and open files explicitly rather than having in-place autosave.

Multi-Device Sync

Pet Dashboard has no server, so "syncing" between devices means putting your pet-dashboard.json file in a folder that your cloud sync service (OneDrive, Google Drive, Dropbox) keeps in sync.

Setup (One-Time)

  1. Make sure your sync service (OneDrive, Google Drive, or Dropbox) is installed and running on both devices.
  2. On Device #1, go to Settings → Save As… and save pet-dashboard.json into your synced folder.
  3. Wait for it to finish syncing to Device #2 (check the sync client status).
  4. On Device #2, go to Settings → Open… and pick that same file from the synced folder.
How It Works The app itself doesn't talk to OneDrive/Google Drive/Dropbox — it just reads and writes the JSON file. The sync client handles the rest.

What Happens When Both Devices Edit

Before every save, the app checks whether the file changed on disk. If it has (meaning the sync client brought in a newer version from your other device), you'll get a prompt:

  • Reload the newer version — discards your unsaved edits on this device.
  • Overwrite — keeps your edits, loses the other device's changes.
Avoid Simultaneous Editing For best results, don't edit on both devices at the same time. If both devices save within a few seconds of each other, whichever the sync client processes last wins — with no warning.

Manual Sync

At any time, go to Settings → Reload latest to pull the latest version from disk. This is useful right when you switch devices.

Data Management

Save / Export

  • Autosave: Once you've opened or saved a file (Chromium browsers only), the app automatically saves your data every 1.5 seconds as you work.
  • Save: Settings → Save writes to the currently open file in place.
  • Save As: Settings → Save As… lets you choose a new location and filename.
  • Export backup: Settings → Export backup downloads the full JSON file for safekeeping.

Open / Import

  • Open: Settings → Open… lets you pick an existing JSON file.
  • Import backup: Same as Open — use it to restore from a backup file.

Export Individual Datasets

Settings → Export data lets you pull out specific datasets as CSV or JSON:

  • CSV — for spreadsheets (Excel, Google Sheets)
  • JSON — for scripts, AI tools, or custom processing

Available datasets include: weight history, vaccinations, expenses, training sessions, journal entries, and more.

Reports

Reports generates printable summaries:

  • Health summary
  • Vaccination summary
  • Expense summary
  • Growth report (with weight chart)
  • Training report

Click "Print / Save as PDF" to print or save any report.

Daily task checklists grouped by time of day (morning/afternoon/evening), plus a calendar view for one-off events.

Expenses

Track spending by category with monthly and yearly totals, a category breakdown chart, and customizable categories.

Journal

Daily notes with mood tracking and tags. Search across all entries.

Track your dog/cat introduction process (scent → visual → shared space), behavior logs, and stress indicators.

Daughter

Track what your daughter does with the puppy during her time: tasks, training help, walks, reading sessions, feeding, rewards, and achievements.

Milestones, fear periods, growth stages, and teething logs — with automatic age calculation from the birthday.

Photo gallery with captions, search, and lightbox view. Photos are embedded in the JSON file — no separate folders needed.

Printable summaries of health, vaccinations, expenses, growth, and training data.

Theme (light/dark/system), file management (open/save/export/import), data export (CSV/JSON datasets), and about information.

Troubleshooting

The page is blank when I double-click index.html

This is expected. The app uses ES modules which browsers block on file:// URLs. Always use the launcher script (start-server.bat on Windows, start-server.sh on macOS/Linux) to run the local server.

My data is gone after reopening the browser

You need to save your data file. Go to Settings → Save As… and save pet-dashboard.json to a permanent location. On your next visit, use Settings → Open… to load it back.

Autosave isn't working

Autosave requires the File System Access API, which is only available in Chromium-based browsers (Chrome, Edge, Opera). Firefox and Safari fall back to download/upload mode. You can manually save with Settings → Save or Export backup.

The app doesn't work offline

You need to install it as a PWA first. Once installed (via the browser's install prompt), the app caches itself and works offline. On mobile, use "Add to Home screen" for the best offline experience.

Search in Health/Expenses/Journal loses focus while typing

This is a known minor issue — the search input briefly loses focus as the list re-renders. The search term is preserved, so just keep typing.

Can't connect from my phone

  • Make sure both devices are on the same Wi-Fi network.
  • Check your computer's firewall — it may need to allow incoming connections on port 8934.
  • Verify your IP address is correct (run ipconfig on Windows or ifconfig on macOS/Linux).

File changed elsewhere conflict

If you see "This file changed elsewhere," it means the sync client brought in a newer version from another device. Choose Reload to get the latest, or Overwrite to keep your local edits.

Service worker not updating after a change

The app uses a cache version string. After updates, you may need to clear your browser cache or open the app in an incognito window to force a fresh install of the service worker.
